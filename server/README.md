# DECORD - צד שרת

`DECORD.m` הוא הרוטינה שהאפליקציה קוראת לה (`/mcall?_ROUTINE=DECORD&_LABEL=...`).

הקובץ שמור באותו קידוד שמוצג ב-Eclipse MDE: אותיות לועזיות קטנות מופיעות כאותיות עבריות, למשל `ôïëåî` = `token`. מעתיקים את הקובץ כמו שהוא לעורך.

## Labels

| Label | הרשאה | תפקיד |
|---|---|---|
| `LOGIN` | ציבורי | בדיקת משתמש/סיסמה מול טבלת OPC, פתיחת session |
| `EXTDATAMCALL` | token | רשימת הזמנות חסומות + שורות |
| `RELEASEORD` | token | שחרור הזמנה |
| `LOGOUT` | token | סגירת ה-session |

## אבטחה (29.10.26)

- **רק `LOGIN` פתוח.** עד עכשיו גם `EXTDATAMCALL` היה פתוח, כך שכל אחד יכול היה לקבל לקוחות, הזמנות ומחירים בלי להתחבר.
- **ה-token בנוי כ-`MR-random`**, ולכן החברה מגיעה עם כל בקשה. קודם ה-MR נלקח מ-`^W($J)` של ה-job שמטפל בבקשה, וזה לא בהכרח ה-job שבו המשתמש התחבר.
- **חסימה זמנית:** אחרי 5 ניסיונות כושלים המשתמש נחסם ל-15 דקות.
- **session אחד למשתמש:** התחברות חדשה מנתקת את המכשיר הקודם, וזה מקשה על כמה אנשים לחלוק יוזר.
- **רשימת משתמשים מורשים (רישוי):** אם `^MPG(MR,"DECORD","USERS",OPC)` מוגדר, רק המשתמשים ברשימה יכולים להיכנס, ומספר הרשומות הוא מספר המשתמשים בחבילה. אם הרשימה ריקה, כל משתמש OPC יכול להיכנס, כמו קודם.
- **שחרור הזמנה:** מותר רק להזמנה קיימת וחסומה, וכל ניסיון נרשם ב-`^MPG(MR,"DECORD","LOG",DATE,TIME,SEQ)=OPC_ORDID_RESULT`.
- **שחרור מוצלח מחזיר `Released`.** קודם הוחזר אובייקט ריק, והאפליקציה הציגה שגיאה.

## Globals

```
^MPG(MR,"DECORD","SESSION",TOKEN,"EXPIRED-AT"|"OPC")
^MPG(MR,"DECORD","BYUSER",OPC)=TOKEN
^MPG(MR,"DECORD","FAIL",OPC)=COUNT_LASTSEC
^MPG(MR,"DECORD","USERS",OPC)=""
^MPG(MR,"DECORD","LOG",DATE,TIME,SEQ)=OPC_ORDID_RESULT
```

## לבדוק אחרי העלאה

1. התחברות תקינה, ובדיקה שה-token שמתקבל מתחיל ב-`MR-`.
2. קריאה ל-`EXTDATAMCALL` בלי header `Authorization` צריכה להיחסם.
3. התחברות עם אותו יוזר בשני מכשירים: המכשיר הראשון מנותק בפעולה הבאה.
4. 5 סיסמאות שגויות ואחריהן הודעת חסימה.
5. שחרור הזמנה: הודעת הצלחה, ובדיקה שנוספה רשומה ב-`LOG`.
6. **לוודא ש-`%HEADER` זמין גם בתוך ה-labels עצמם, ולא רק ב-`AUTH`.** אם הוא לא זמין, הקוד חוזר להתנהגות הקודמת (MR מ-`^W`).
